# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button under the repository's **Security** tab (private vulnerability reporting). Do not open a public issue.

Include the affected URL or file, steps to reproduce and the impact you expect. You will get an acknowledgement as soon as possible.

## Scope

This repository contains only the public landing page. The JARVIS cluster itself, its infrastructure repository and internal services are not reachable from the internet and are out of scope.
